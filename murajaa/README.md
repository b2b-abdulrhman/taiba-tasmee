# مراجعة طيبة النشر (لمستخدمي VoiceOver)

صفحة مراجعة متواصلة: يسمّع الحافظ دون توقف، وعند الخطأ الواضح تُسمَع نغمة ثم الكلمة الصحيحة بصوت الشيخ أيمن سويد، ثم يعود الاستماع تلقائيًا.

- `timing.json`: بداية ونهاية كل كلمة من كل بيت في تسجيل الشيخ (النسخة المسرّعة، ١:٣٩:١١)، مستخرجة آليًا بمحاذاة قسرية (CTC forced alignment) بنموذج Omnilingual ASR.
- `alts.json`: الكلمات التي قرأها الشيخ بلفظ يختلف عن نص هذه النسخة، وتُقبل كذلك عند التسميع.
- ملف الصوت **غير مرفوع هنا**؛ يُختار مرة واحدة من الجهاز ويُحفظ محليًا فيه.
- البناء: `murajaa.src.html` + `../taiba_data.json` + `timing.json` + `alts.json` ← `index.html`.
