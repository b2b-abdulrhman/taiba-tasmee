# تسميع طيبة النشر

تطبيق ويب لتسميع منظومة «طيبة النشر في القراءات العشر» للإمام ابن الجزري (١٠١٥ بيتًا) بالصوت، على طريقة تطبيق ترتيل: تُخفى الأبيات، ويُسمِّع الحافظ، فتظهر الكلمات الصحيحة بالأخضر والأخطاء بالأحمر والساقطة بالبرتقالي.

- النص: نسخة المكتبة الشاملة، تحقيق الشيخ محمد تميم الزعبي (دار الهدى، جدة، ١٤١٤هـ)، مع حذف التعليقات بين الأقواس.
- التعرّف على الصوت: من المتصفح (يُنصح بـ Chrome على أندرويد).

## التعديل
- الكود في `app.src.html` والنص في `taiba_data.json`.
- بعد أي تعديل: `python3 build.py` لتوليد `index.html`.
